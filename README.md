# MusicNest — Afreen Music Streaming

This repository is intentionally maintained as a **distribution-only package**.

## What is shared here
- `README.md`
- `screenshots/` (app preview images)
- `apk/` (installable Android APK file)

## What is not shared here
- Source code files
- Build scripts and development configuration

If you are here to download the app, use the APK file inside the `apk/` folder.
