# 🔒 Security Policy

We take the security of MusicNest and its users seriously. As an open-source project handling media streaming and network calls, maintaining secure dependencies and safe code execution is a top priority.

---

## Supported Versions

Only the latest published release receives active security patches.

| Version | Supported          |
| ------- | ------------------ |
| v1.1.x  | :white_check_mark: |
| < v1.1  | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability (such as API credential leakage, insecure local data storage, or arbitrary code execution vectors):

1. **Do NOT open a public issue.**
2. Send an email to the maintainer or open a **Private Security Advisory** directly on GitHub under the **Security** tab of this repository.
3. Provide a clear description of the vulnerability, reproduction steps, and potential attack vectors.

Maintainers will review the report, issue a fix in a private branch, and release a patched version alongside a public advisory.
